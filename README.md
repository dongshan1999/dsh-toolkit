# dsh-toolkit

**简体中文** | [English](./README.en.md)

一个 DSH 桌面端（DeepSeek Harness App）Bundle：把八件互相独立的事装在一起，七个面板再由「工具集」这一个侧边栏入口统一收口。

| 组件 | 面板 | 给 Agent 的工具 | 一句话 |
| --- | --- | --- | --- |
| **image-gen** | 「工具集」→「图片生成」 | `generate_image` | 调任意 OpenAI 兼容生图接口生成 / 编辑图片，管图库、提示词与收藏 |
| **token-usage** | 「Token 用量」（order 50，独立面板） | — | 统计全部会话的 Token 消耗与成本，含近一年活跃度热力图 |
| **model-test** | 「工具集」→「模型测试」 | — | 测 DSH 已配置模型的连通性、首字延迟与输出速度，并按模型名补参数 |
| **notifications** | 「工具集」→「通知」 | — | 16 类事件的提醒中心；提醒只走系统通知，应用内零打扰 |
| **mcp** | 「工具集」→「MCP」 | — | profile `cordis.patch.yml` 里 MCP server 的列 / 增 / 改 / 删 / 启停 / 探活 |
| **skill** | 「工具集」→「Skill」 | — | 六个扫描根下 skill 的浏览、编辑、新建、删除与启停 |
| **clipboard** | 「工具集」→「剪贴板」 | — | 粘贴超长文本时自动落成文件，输入框只留一行 `@"路径"` 引用 |
| **annotations** | 「工具集」→「注释」（会话内另有两个挂载点） | — | 对话正文里划词就能加注释，注释栏里写，发送时自动拼成 `[注释 N] "原文"：内容` 进草稿 |
| **toolkit** | 「工具集」（order 48） | — | 把上面七个面板收进同一套界面，外加内置的只读「设置」分页 |

各业务组件可以单独启用：面板 key 不同（`image-gen` / `token-usage` / `model-test` / `notifications` / `mcp` / `skill` / `clipboard` / `annotations`），路由前缀也不同。
「工具集」是外壳：客户端界面负责侧边栏入口与分页切换，Host 侧只有一个只读的设置路由。

> **设计原则：不绑定任何服务商。** 插件不内置厂商模型、默认地址或私有网关——
> 模型目录完全由你自己添加，任何实现了标准 `POST /images/generations` 的服务都能接。
> `model-test` 同理：它只测 **DSH 自己已经配置并可路由**的模型，不引入第二套凭证或地址。

| 项目 | 要求 |
| --- | --- |
| DSH | **0.2.1 及以上**（开发与验证版本 `0.2.1-rc.2`） |
| 运行环境 | DSH 桌面端（DeepSeek Harness App；客户端插件按 `client.platform: web` 加载），Node.js 18+（用命令行安装插件时需要） |
| 许可证 | [MIT](./LICENSE) |

界面文案为简体中文；本文中出现的界面文字、文件名、路由与标识符均保持原文。

本文是上手索引；每个组件的需求、约束、接口契约与验收口径，见 [`docs/`](./docs/) 下的功能案。

## 安装

DSH 桌面端 **0.2.1+**，并有一个 profile（默认位于 `~/.dsh/profiles/<profile>/`）。

### 方式一：作为依赖安装（推荐）

1. 在 profile 的 `package.json` 里声明依赖与 bundle：

   ```jsonc
   // ~/.dsh/profiles/<profile>/package.json
   {
     "dependencies": {
       "dsh-toolkit": "^0.2.0"
     },
     "dsh": {
       "profile": {
         "bundles": [
           // …
           "dsh-toolkit"
         ]
       }
     }
   }
   ```

2. 让 DSH 加载它：用 `plugin_manager` 的 `install_bundle`（target 填 `dsh-toolkit`），或重启 DSH。
   返回 `application: restart-required` 时，重启后即可生效。

### 方式二：本地 link 安装

```jsonc
"dependencies": { "dsh-toolkit": "link:/absolute/path/to/dsh-toolkit" }
```

> 🟡 `remove_bundle` 会把上面两处声明**一并从 profile 的 `package.json` 删掉**，
> 重新安装前要手动加回，否则包管理器会去 registry 找 `link:` 本地包并失败。

## 组件速览

每个组件一句起点，细节都在功能案与组件 README 里。

### 图片生成（image-gen）

「工具集」→「图片生成」→「设置」→ **「+ 添加模型组」**（组名 / API Key / 链接）→ **「获取模型」** 勾选后保存 → 选默认模型，回「文生图」即可。
收藏不是第二个目录：图片只有 `image-gen/images/` 一份，`favorites.json` 只存标记。

详见：[功能案-图片生成](./docs/功能案-图片生成.md)

### Token 用量与活跃度（token-usage）

独立面板（order 50），不在「工具集」分页里。统计全部会话的 Token 与成本，价目三层合并
（内置表 → 用户覆盖 → models.dev 同步），生图按张单独计费；近一年活跃度热力图按天聚合。

详见：[功能案-token用量](./docs/功能案-token用量.md)

### 模型测试（model-test）

目录来自 DSH 自己的模型路由（不引入任何第二套凭证）。可整批、整组或只测单个模型，
看首字延迟 / 总耗时 / 每秒 token；能按模型名自动补 `temperature / maxTokens / reasoningEffort`，
并可一键把参数写进 DSH 真实配置（`fill` 或 `replace`，带 revision CAS）。
组默认收起，点组头（组名 / 箭头 / 空白处）展开；点「测试本组」会自动展开该组。

详见：[功能案-模型测试](./docs/功能案-模型测试.md)

### 通知（notifications）

订阅 16 类事件（会话完成、需要权限、模型失败、子智能体结局……），提醒只走**系统通知中心**
（停留、点击跳回会话），应用内部不弹任何东西；面板是历史记录与场景开关，条目按
**成功 / 待审批 / 待回答 / 失败** 四色区分。系统通知不能自定义颜色，标题前带图标区分同一套四类：
🟢 成功 · 🟠 待审批 · 🔵 待回答 · 🔴 失败 · 🟡 警告。会话一结束最多 1.5 秒就提醒（增量心跳），
同一会话连跑多轮时成功类通知一分钟内只弹一条；你正看着那个会话时它不弹（审批 / 提问 / 失败照弹）。
未读状态与去重计数落 `notifications/queue.json`，重启不丢。

详见：[功能案-通知](./docs/功能案-通知.md)

### MCP 管理（mcp）

列出当前 profile `cordis.patch.yml` 里所有 MCP server（含 disabled），支持新增 / 编辑 / 删除 /
启停与一次性探活；写 YAML 时字节级保留 `!!js` 与注释，密钥默认脱敏，`reveal=1` 才给原文。

详见：[功能案-mcp管理](./docs/功能案-mcp管理.md)

### Skill 管理（skill）

六个扫描根全量列出（坏文件也列并给出原因），可写根内新增 / 编辑 / 删除 / 启停；保存前按官方规则
校验 frontmatter，磁盘是真相、官方服务只是旁证。

详见：[功能案-skill管理](./docs/功能案-skill管理.md)

### 剪贴板（clipboard）

从终端、CI、日志面板复制的长文本，粘进输入框会撑满整个 composer。这个组件在粘贴时拦截：
超过阈值（默认 2000 字符 / 30 行）的文本先落成
`$DSH_HOME/dsh-toolkit/clipboard/<日期>/<HHmmss>-<sha1 前 8 位>.<ext>`，输入框里只插一行
`@"绝对路径"`（无空白时写 `@路径`），Agent 读到的是文件引用而不是几千字原文。
扩展名只看剪贴板带了哪种文本格式（单份按格式取 `.txt/.html/.csv/.md`，多份统一 `.txt`），
不按内容猜；图片与文件粘贴完全不介入。正文完整写入、不按大小截断。
面板可改阈值、开关自动转换、预览与删除条目；另可开「自动清理」（默认关，按保留天数或总量上限清，只动自己的日期目录）。

详见：[功能案-剪贴板](./docs/功能案-剪贴板.md)

### 会话注释（annotations）

读长会话时想对某句话提意见，只能用文字描述位置。这个组件把「指代」变成划词：在对话正文里选中文字，
**鼠标一放开**（不等停顿）选区就亮起预览高亮，并浮出带下一个编号的按钮「＋ 注释 N」；点它，输入框上方
的注释栏出现一条可编辑条目（不弹浮层），写好后折叠成一行。保存后原文留下高亮，并在选区末尾挂一个
蓝底白字的编号角标；同时把注释块追加进草稿交给模型 —— 短引用一行 `[注释 N] "原文"：注释`，保存即**另起一段**写入 `[注释 N] 第 12–18 行 "完整原文"：注释`（走 Lexical 的 paste，换行才会变成真段落）；注释栏里保存后收成「注释 N」小标签，悬停它弹出位置、完整划词内容与注释，点它回到编辑态。删掉这条注释，
高亮和角标一起消失。
本轮发送后注释清空、编号从「注释 1」重新开始（不归档）。
数据按会话存放在 `$DSH_HOME/dsh-toolkit/annotations/`，原文被改动后会标成「原文已变」而不是画错位置。

详见：[功能案-对话注释](./docs/功能案-对话注释.md)

### 工具集壳（toolkit）

侧边栏只留一条「工具集」，点开后在面板顶部切分页：图片生成 / 剪贴板 / 模型测试 / 通知 / MCP / Skill / 注释 / 设置。
切走的分页会卸载（未保存表单重置）；「设置」是壳内置的只读页，显示各组件数据落在哪、是否已创建、
多大、何时改过。

详见：[功能案-工具集壳](./docs/功能案-工具集壳.md)
